# Cursor CLI 多账户管理接入可行性调研

调研与范围评审日期：2026-11-13

项目：Paseo Accounts（`@jgreys/paseo-accounts`）

代码基线：`b7e043fdb7c92087c70727a1d7b0155e0b6d6ac3`

范围：Paseo 内启动的 Cursor CLI 会话，不涉及 Cursor IDE。本文是调研与实现建议，尚未实现，不代表开发方案已经获批。

## 结论与范围原则

Cursor CLI 的多账户接入具有官方接口基础。推荐采用 **Cursor 用户 API Key + 现有账户适配器 + Paseo 的 Cursor/ACP provider**，尽量保持与现有账户功能一致。

本次范围校正：避免过度开发应以“不重复建设、不给未知能力作保证”为标准，不应为了缩小范围禁用原框架已经提供的功能。高确定性功能纳入交付；依赖 Cursor 行为的功能先验证，再选用既有路径；仅缺少接口依据的功能暂缓。

Cursor 用户 API Key 是 Cursor 自己的认证凭据，与 OpenAI、Anthropic 等供应商 API Key 不同。目标账户是否可用及其计费方式仍需实测，不能把技术接入等同于订阅额度已经验证。

## 功能范围与确定性

| 功能 | 范围决定 | 实现与验证边界 |
| --- | --- | --- |
| 添加、命名、删除账户 | 纳入 | 复用 OpenCode 粘贴密钥、现有 RPC 和原子写入；保存成功与认证有效分开表达。 |
| 默认账户、单会话选账户、Follow default | 纳入 | 复用现有绑定、默认值与启动环境注入，不另建路由。 |
| 账户优先级、项目文件夹绑定、启用/禁用 | 纳入 | 复用通用选择规则及已有可用账户约束；迁移行为取决于下述会话便携性。 |
| CLI 原有登录识别 | 纳入只读检测 | 通过官方状态命令识别；成功时列为 CLI 登录，不读取或复制其秘密值。非结构化输出只解析已验证字段，不能可靠识别时显示说明。 |
| 已有会话手动切换 | 纳入 | 能跨账户恢复则重开；未确认时采用框架已有的新建会话交接路径，不直接禁用切换。 |
| 批量切换 | 纳入现有语义 | 便携会话沿用批量重开；非便携且已有历史的会话沿用逐个处理及跳过原因。 |
| 默认变更、禁用、删除后的协调 | 纳入现有语义 | 复用便携/非便携分支，遵守“移动打开会话”设置与忙碌会话规则；不承诺非便携历史会话自动原地迁移。 |
| 限额或认证失效后的自动切换 | 纳入接入与验证 | 复用现有开关、选账户、限次、重开及继续机制；只对已验证的 Cursor 错误信号触发，未识别错误保留原状。 |
| 跨供应商继续、切换记录与已有通知 | 纳入现有开关和规则 | 复用既有历史交接、权限档位匹配、时间线和通知；不新增通知渠道或默认开启可选功能。 |
| 未知用量下的账户排序 | 纳入 | 直接复用未知用量评分、优先级和默认账户兜底，不显示为“剩余最多”。 |
| 个人剩余额度、额度预测、提前切换 | 暂不承诺 | 缺少已确认的个人用量接口；显示“暂不支持查询”，未知用量不触发阈值切换。 |
| 银行重置额度、付费额外用量 | 不实现 Cursor 专用支持 | 没有已确认接口，沿用适配器的不支持说明；不仿造 Claude 特性。 |
| 浏览器添加多个账户 | 条件支持 | 官方有登录流程，但必须先证明认证存储隔离；该验证不阻塞 API Key 路线。 |

“纳入”表示适配范围，并非宣称实测通过。允许个别未知信号暂不触发，不得将网络故障等泛化为账户耗尽。

## 会话切换：复用已有两条路径

Cursor 官方提供 `--resume` 和 ACP `session/load`，但本次查阅资料未确认跨账户恢复保证。不能据此直接设置 `portable = true`。

- 跨账户恢复实测通过后，采用便携路径：账户环境变更后重开原会话，忙碌会话回合结束再处理，批量切换与默认账户联动按现有规则执行。
- 验证前或恢复不受支持时，采用非便携路径：已有历史的会话保持原账户绑定，用户手动切换时通过 `continueInNewAgent` 在目标账户新建会话并交接历史。批量操作、默认值变更等遵守框架非便携会话规则，不新建第二套迁移系统。
- 同账户恢复仍需验证；若目标 CLI/provider 不具备该能力，应明确说明缺口，不能用新建会话冒充恢复成功。

`portable` 是适配器级开关，不能假定框架已支持逐次失败后自动改走另一条路径。采用哪条路径由验证结果决定，不为兼容性新增动态探测或多级恢复框架。

当前非便携路径部分提示写死为 ChatGPT/Codex。接入 Cursor 时只对受影响提示与历史来源标签作必要泛化，避免用户看到错误供应商名称。交接会将对话发送给目标账户或供应商，沿用现有操作说明与隐私边界。

## 自动化：沿用机制，验证输入

没有个人用量接口不妨碍响应明确限额错误。本项目的 OpenCode、Pi 等适配已存在“无用量展示、根据错误切换”的模式，Cursor 可沿用。

实现只需补充经验证的 Cursor 限额/退出登录识别，接入已有 `autoSwitch`、`autoContinue`、切换频次保护、账户选择与时间线记录。认证失效、明确额度耗尽、短期限流及网络错误必须区分；优先采用结构化错误，文本规则需有脱敏真实样本支撑，不新建通用错误分类服务。

缺少真实样本时可完成接口与模拟验证，但不能宣称自动切换已实测可用；无法确认的错误不自动换号。额度重置时间未知时，复用或局部适配现有不可用标记与“标记可用”操作，验证不会立即选回耗尽账户；不虚构官方重置时间或新增定时探测服务。

跨供应商继续保持现有可选开关与模式权限约束，Cursor 仅作为正常接入的来源或目标，不改变默认开关和其他供应商顺序。切换后继续也遵守原设置，不在尚未成功启动目标会话时发送继续消息。

## 必要改动与复用位置

| 位置 | 改动边界 |
| --- | --- |
| `shared/model.ts`、`server/families.ts` | 增加 `cursor`、名称和认证覆盖变量识别，按现有顺序约定加入回退目标，补齐穷举映射。 |
| `server/adapter.ts`、新增 `server/cursor.ts` | 实现现有 `FamilyAdapter`：认证状态、API Key 输入保存、环境注入、用量不支持说明、已验证的限额与认证错误识别。 |
| `server/opencode.ts`、`server/json-file.ts` | 复用密钥登录和 `writeJsonAtomic` 模式；只做遮蔽输入、防回显所需局部调整，不新增凭据服务。 |
| `server/binaries.ts`、`index.server.ts` | 注册适配器并按配置解析命令、前缀参数；provider ID 为 `cursor`，可执行文件通常为 `agent`，不能直接混用。 |
| `server/service.ts`、`server/handoff.ts` 与账户界面 | 复用绑定、优先级、文件夹规则、切换及交接；泛化必要的供应商文案，不另建迁移机制。 |

先确认目标 Paseo 已有 Cursor provider 或可通过自定义 ACP 配置运行 `agent acp`。若已有入口可用，只补配置；若存在必须修改 Paseo 核心才能解决的缺口，单独报告并确定范围，不默认扩展为新的 provider 项目。

不改写通用适配器架构，不引入能力注册平台、代理授权系统或外部凭据依赖；确有现有分支不适用时做局部修正，并验证其他供应商行为。

## 凭据与端点安全

- 新增账户密钥保存在插件账户目录，目录 `0700`、文件 `0600`，复用原子写入。删除插件账户会删除本地密钥，不代表撤销服务端密钥。
- 输入遮蔽；密钥不进入账户状态、日志、通知、错误文本或命令行参数，只向对应 CLI 进程注入所选密钥。
- 验证 `CURSOR_API_KEY`、认证令牌与原有本地登录的优先级，清理会覆盖账户选择的冲突项。CLI 原有登录按现有 main 账户语义处理，不复制其认证文件，不强制修改全局登录。
- 本机帮助信息支持 `CURSOR_API_ENDPOINT` / `--endpoint`。插件管理的密钥默认仅发往经核验的官方端点；带独立认证或自定义端点的 provider 按现有“自带认证”原则不接管，并明确说明。无法保证目标时拒绝注入密钥，不静默覆盖用户配置。
- 不复制其他供应商凭据、不默认共享整个 Cursor 目录，不接触 Cursor IDE 数据库。进程环境仍可被同用户进程或后代进程读取，不宣称强安全隔离。

浏览器登录可复用 `agent login` 与 `NO_OPEN_BROWSER=1`。只有证明配置目录能隔离登录、刷新和退出后才开放多账户浏览器登录；不以改变 `HOME` 或共享全套配置替代验证。

## 验证与验收

| 验收组 | 必要证据 |
| --- | --- |
| 基础接入 | 目标版本可通过现有 Cursor/ACP provider 收发消息、处理权限与结束会话；目标账户 Key 可用及认证优先级已验证。 |
| 账户管理与路由 | 添加/命名/删除、CLI 登录识别、默认账户、显式绑定、优先级、文件夹与启用/禁用符合现有规则；两个账户并行不串号。 |
| 会话切换 | 验证同账户恢复，确定便携性；按选定路径验证手动、批量、默认变更及删除/禁用后的协调；非便携会话交接显示正确来源。 |
| 自动与回退 | 用真实脱敏错误样本验证限额/认证失效触发，普通限流和网络错误不误换；核对限次、继续开关、可选跨供应商交接与模式权限。 |
| 凭据与回归 | 权限、防回显、端点及冲突认证符合要求；执行类型检查和受影响测试，其他供应商行为不回归。 |

真实错误触发难以重现时，可用采集样本回放验证分类与框架联动，记录“样本验证”而非“真实额度耗尽实测”。缺少测试凭据时继续可独立完成的静态与模拟工作，但保留真实集成验收待办。

只声明实际测试的平台与版本，不要求基础接入先完成全平台矩阵。真实请求可能消耗测试账户额度。

## 暂缓事项

仅暂缓缺少确定接口依据或超出当前范围的内容：个人实时额度与套餐查询、提前切换/预测、Cursor 专用重置接口、未经验证的浏览器认证隔离，以及普通终端启动包装命令。团队 Admin API 需要额外权限，不作为个人账户适配的必选依赖。

这些是能力边界；需要时再单独评估，不预先搭建扩展框架。
